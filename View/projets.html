Projets C/C++

embedded-digicode-projet

Projet de digicode avec un Raspberry Pi Pico utilisant un clavier matriciel pour saisir un code. Le système vérifie le code saisi par rapport à un code prédéfini et affiche un message de confirmation ou d’erreur via la console. La saisie se réinitialise automatiquement après 15 secondes d’inactivité.

Trois LEDs indiquent l’état du système : LED verte pour code correct, LED rouge pour code incorrect, et LED orange si le délai de saisie est dépassé. Le développement a été réalisé avec PlatformIO sous VSCode, facilitant la gestion et le déploiement du code sur le microcontrôleur. Le matériel utilisé comprend un Raspberry Pi Pico, un clavier matriciel, des LEDs et les câbles nécessaires au câblage.

Project client léger LS Motors — LS Motors

LS Motors est une plateforme web fonctionnant comme une véritable concession automobile digitale. Elle permet de connecter les vendeurs et les clients autour d’un catalogue complet de véhicules, organisé par marques et catégories, avec une présentation claire et professionnelle.

Les vendeurs disposent d’un espace dédié où ils peuvent se connecter, gérer leurs ventes, suivre les rendez-vous, organiser les catégories de véhicules et mettre à jour le catalogue. Chaque modèle peut être ajouté, modifié ou retiré, avec photos, caractéristiques techniques et disponibilité en temps réel.

Les clients peuvent créer un compte, consulter les véhicules, réserver un modèle, l’acheter ou envoyer un message pour prendre rendez-vous avec un vendeur. Toutes les interactions sont centralisées : messagerie, demandes d’essai, suivi des réservations et informations sur les véhicules.

Le client accède alors à son tableau de bord où il retrouve le statut de sa demande, les informations du véhicule choisi et les détails du rendez-vous avec son conseiller LS Motors.

Project RATP — Programmation orientée objet en Java

Ce dépôt illustre et fait pratiquer les concepts fondamentaux de la POO en Java, à travers un exemple concret inspiré de la RATP (réseau de transport parisien). Le projet sert de support pédagogique pour modéliser stations, lignes, bus, métros, et leurs interactions.

Les objectifs incluent la compréhension et la mise en œuvre des classes (attributs, méthodes, constructeurs), l’exploration de l’héritage et du polymorphisme, ainsi que l’application de ces notions dans un scénario réaliste de réseau de transport pour concevoir une architecture claire, réutilisable et évolutive.

Le projet propose une modélisation orientée objet du domaine (stations, lignes, véhicules, itinéraires), permettant d’expérimenter la conception, l’encapsulation et les relations entre objets, tout en renforçant les bonnes pratiques de développement en Java.

Project client lourd LS Motors Admin Console

LS Motors Admin Console est une application de bureau Java Swing constituant le client lourd du projet LS Motors Elle permet à l'administrateur de la concession LS Motors Dealership — une concession automobile dans un univers de jeu de rôle (GTA V RP) — de gérer toutes les données utilisées par le site web LS Motors : les utilisateurs(admins, employés, joueurs) les marques automobiles disponibles (plus de 50 marques GTA V) , le catégories de véhicules (Sport, SUV, Berline, Moto...), le catalogue de véhicules avec prix et disponibilité ainsi que et l''historique des ventes hebdomadaires par employé et la marge globale appliquée automatiquement sur les prix du site.

L’application suit une architecture MVC, offrant une structure claire et modulaire. Elle s’intègre dans un écosystème plus large comprenant également un client léger en PHP, illustrant la complémentarité entre interface lourde et interface web.

Ce projet met en pratique les principes essentiels de la POO en Java à travers un cas concret. Il permet d’expérimenter la conception d’interfaces graphiques, la séparation des responsabilités via le MVC, et l’organisation d’un projet Java structuré, réutilisable et évolutif.
